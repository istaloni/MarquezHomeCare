# Marquez Family Home Care — blog source

This folder holds the Quarto source for the website's blog. Rendering it builds the
blog into `../blog/`, which the website serves at `/blog/`.

```
Marquez Homecare/
├── index.html          website home page (has a "Blog" link in the nav)
├── styles.css          website styles
├── images/
├── blog/               ← generated by Quarto. Don't edit by hand.
└── blog-src/           ← you edit here
    ├── _quarto.yml     site settings, navbar, footer
    ├── brand.scss      design-system colors and fonts mapped onto Quarto's theme
    ├── styles.css      brand components, plus the logo and orchid mark drawn with CSS
    ├── publish.R       copies _site/ into ../blog/ after each full render
    ├── index.qmd       blog home page (lists all posts)
    ├── images/         logo, mark and favicon (copied from Marketing/Logo)
    └── posts/
        ├── _metadata.yml   shared post settings (author, freeze)
        └── 2026-11-02-who-needs-care-at-home/index.qmd
```

## One-time setup

1. Install Quarto: <https://quarto.org/docs/get-started/>
2. In R: `install.packages(c("tidyverse", "tidycensus", "scales", "knitr", "rmarkdown"))`
3. Get a free Census API key at <https://api.census.gov/data/key_signup.html>, then run
   `tidycensus::census_api_key("YOUR_KEY", install = TRUE)` and restart R.

## Build the blog

From a terminal in this folder (or the RStudio Terminal tab):

```bash
quarto render
```

The first render runs the R code and calls the Census API. After that, posts are
**frozen**: the results are saved in `_freeze/`, and later renders reuse them without
calling the Census again. Commit `_freeze/` to git.

To preview while you write: `quarto preview` (this updates `_site/` only; run
`quarto render` when you're ready to update `../blog/`).

To refresh a post's numbers on purpose:

```bash
quarto render posts/2026-11-02-who-needs-care-at-home/index.qmd
quarto render
```

## Add a new post

1. Create a folder in `posts/` named `YYYY-MM-DD-short-title/` with an `index.qmd` inside.
2. Start it with:

   ```yaml
   ---
   title: "Your title in sentence case"
   description: "One sentence for the blog listing."
   date: 2026-11-15
   categories: [Caregiving, Families]
   ---
   ```

3. Run `quarto render`, then commit and push.

## Writing in the brand voice

- Calm, plain sentences. Sentence case. No exclamation marks or emoji.
- Say "your mom", "your loved one", "clients", never "patients" or "the elderly".
- We're non-medical: say "support", "assistance", "help with".
